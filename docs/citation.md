# Citing gp3bayespy

If `gp3bayespy` contributes to your research, cite the **software version you
actually used**.

## Current release: v0.6.1

The current repository citation metadata in
[`CITATION.cff`](https://github.com/stefanosbalaskas/gp3bayespy/blob/main/CITATION.cff)
identify **gp3bayespy 0.6.1**, released on 2026-09-21.

Until a version-specific archival DOI is minted for v0.6.1, cite the version
explicitly and include the stable release URL:

**Balaskas, S. (2026). _gp3bayespy: Contract-First Bayesian Workflows for
Hierarchical Behavioural Data in Python_ (Version 0.6.1). GitHub.
https://github.com/stefanosbalaskas/gp3bayespy/releases/tag/v0.6.1**

```bibtex
@software{balaskas_gp3bayespy_061_2026,
  author  = {Balaskas, Stefanos},
  title   = {gp3bayespy: Contract-First Bayesian Workflows for Hierarchical Behavioural Data in Python},
  year    = {2026},
  version = {0.6.1},
  url     = {https://github.com/stefanosbalaskas/gp3bayespy/releases/tag/v0.6.1}
}
```

## Archived v0.5.0 DOI record

[![Archived v0.5.0 DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22150746.svg)](https://doi.org/10.5281/zenodo.22150746)

The DOI **10.5281/zenodo.22150746** identifies the archived **gp3bayespy
0.5.0** software record only:

**Balaskas, S. (2026). _gp3bayespy: Contract-First Bayesian Workflows for
Hierarchical Behavioural Data in Python_ (Version 0.5.0). Zenodo.
https://doi.org/10.5281/zenodo.22150746**

```bibtex
@software{balaskas_gp3bayespy_050_2026,
  author  = {Balaskas, Stefanos},
  title   = {gp3bayespy: Contract-First Bayesian Workflows for Hierarchical Behavioural Data in Python},
  year    = {2026},
  version = {0.5.0},
  doi     = {10.5281/zenodo.22150746},
  url     = {https://doi.org/10.5281/zenodo.22150746}
}
```

Do not use the v0.5.0 DOI as though it identifies v0.6.1.
