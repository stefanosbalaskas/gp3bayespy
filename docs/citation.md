# Citing gp3bayespy

If `gp3bayespy` contributes to your research, cite the software version you used.

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22150746.svg)](https://doi.org/10.5281/zenodo.22150746)

## Preferred software citation

**Balaskas, S. (2026). _gp3bayespy: Contract-First Bayesian Workflows for Hierarchical Behavioural Data in Python_ (Version 0.5.0). Zenodo. https://doi.org/10.5281/zenodo.22150746**

## BibTeX

```bibtex
@software{balaskas_gp3bayespy_2026,
  author  = {Balaskas, Stefanos},
  title   = {gp3bayespy: Contract-First Bayesian Workflows for Hierarchical Behavioural Data in Python},
  year    = {2026},
  version = {0.5.0},
  doi     = {10.5281/zenodo.22150746},
  url     = {https://doi.org/10.5281/zenodo.22150746}
}
```

## Machine-readable citation metadata

The repository includes [`CITATION.cff`](https://github.com/stefanosbalaskas/gp3bayespy/blob/main/CITATION.cff), which GitHub can render directly as a citation.

The DOI above identifies the archived **0.5.0 software record**. For analyses that also rely on the original R implementation, cite the [`gp3bayes` R reference](https://cran.r-project.org/package=gp3bayes) where appropriate.
