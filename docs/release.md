# gp3bayespy 0.6.0

Version **0.6.0** adds contract-first Bayesian multilevel gaze mediation
while preserving the frozen **gp3bayes 0.5.0** parity baseline.

## Release requirements

The exact release commit must pass:

- repository-wide 100% branch-aware coverage;
- zero missing statements;
- zero missing branches;
- zero coverage exclusions;
- Ruff;
- mypy;
- Ubuntu, Windows, and macOS across Python 3.11–3.13;
- the all-extras integration lane;
- strict MkDocs build and site audit;
- wheel/sdist build and twine validation;
- fresh installation from the exact release wheel.
